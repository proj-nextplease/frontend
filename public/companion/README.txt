Thả 3 ảnh minh hoạ "người bạn đồng hành" vào đây với đúng tên sau:

  simple.png   -> thẻ "Đơn giản"      (bàn tay chỉ)
  trust.png    -> thẻ "Đáng tin cậy"  (huy hiệu tick)
  smart.png    -> thẻ "Thông minh"    (bóng đèn)

- Hỗ trợ .png hoặc .svg (nếu dùng .svg thì đổi đuôi trong IdealCompanion.jsx).
- Nền trong suốt (transparent) là đẹp nhất; kích thước ~ 400x400.
- Khi có file, ảnh sẽ tự thay cho hình vẽ mặc định. Chưa có file thì hình vẽ mặc định vẫn hiển thị (không lỗi).
- Chỉ dùng ảnh bạn có quyền sử dụng.
